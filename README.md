# Happy Birthday Mithra ❤️

Interactive birthday experience with four stages: birthday pop-up, draggable ribbon letter, video transition, and final lock screen.

## Assets
Create `assets/` and add:
- `birthday.mp3` — cracking/pop + birthday tune for the opening
- `kumki 1.mp3` — background song for the letter page
- `break 1.mp4` — video for page 3

## Run
Open `index.html` through a local static server or deploy with GitHub Pages.
